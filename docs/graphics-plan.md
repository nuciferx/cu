# แผนภาพโต้ตอบรายกฎ — บทตัวอย่าง "ระยะร่นและที่ว่างรอบอาคาร" (สไลด์ 52–69)

เจ้าของงานสั่ง: "ทุกกฎทำเป็นกราฟฟิกได้หมด" ⇒ ครบทั้ง 16 กฎ ไม่มีกฎไหนเป็นข้อความล้วน
ที่มา: `docs/rules-table.md` · `src/rules/setback-rules.js` · `src/rules/check.js` · รูปสไลด์ 55, 59, 63, 64, 66, 69 (ดูจริง)

**หลักที่ใช้ทุกกฎ**
- ตัวเลขเกณฑ์ทุกตัวอ่านจาก `setback-rules.js` (`rule.params`) เท่านั้น เอกสารนี้อ้างเป็นชื่อพารามิเตอร์ ไม่คัดตัวเลขซ้ำนอกจากที่ตารางกฎมีอยู่แล้ว
- ภาพวาดจากผลของตัวตรวจกฎเท่านั้น (ตามสเปก) ⇒ กฎใหม่ทุกข้อต้องมีตัวตรวจใน `check.js` ก่อนจึงจะมีผ่าน/ไม่ผ่าน
- กฎ needs-review: ติดป้าย "จุดที่ต้องตรวจ" สีเหลืองที่หัวขั้นและข้างตัวเลข · แสดงผลได้ แต่ไม่ล็อกเป็นคำตอบถูก
- ตัวเลขที่ไม่มีในตาราง = เขียนว่า "ต้องหาตัวเลข" (ดูรายการรวมท้ายเอกสาร)
- ปุ่มร่วมทุกฉาก: เริ่มค่าใหม่ · สลับมุมมอง 3 มิติ/จากด้านบน · แสดงที่มา (ข้อความตัวบทคำต่อคำ)

## ฉากที่ใช้ (สรุป 5 ฉาก)

| ฉาก | ชื่อ | มุมมอง | ใช้กับกฎ |
|---|---|---|---|
| ก | ที่ดินภายนอก (มีอยู่แล้ว) | 3 มิติ + จากด้านบน | canal-setback · wall-opening-distance · open-area-residential · wall-opening-floors-wording · road-side-d-150 · garage-boundary-figure · tennis-fence-building |
| ข | ผังห้อง (ชั้นหนึ่งมองจากด้านบน) | จากด้านบนเป็นหลัก | min-unit-area · bedroom-size · dorm-room-size · corridor-width |
| ค | ภาพตัดผนัง (มองด้านข้าง/ตรงหน้าผนัง) | 2 มิติแบบแบน | solid-wall-near-boundary · solid-wall-definition |
| ง | ตึกแถวหลายคูหา | จากด้านบน + 3 มิติเบาๆ | rowhouse-back-space · rowhouse-gap-between-rows |
| จ | แผนภาพที่มากฎหมาย (ไทม์ไลน์ 2 มิติ ไม่มีฉาก 3 มิติ) | แบน | law-title-year |

## ส่วน 1 — ฉากก (ที่ดินภายนอก)

ค่าเดิมของ SceneParams ที่ฉากนี้มีอยู่แล้ว: `lot{width,depth}` · `road{width}` · `canal{width}|null` · `building{x,z,width,depth,floors,height,use}`

### `open-area-residential` · สไลด์ 53 · needs-review
- **ฉาก**: ก (มุมบน)
- **ผู้เรียนปรับ**: ความกว้าง/ลึกอาคาร (ตัวเลื่อน ทีละ 0.5 ม. · ช่วงให้ครอบ 0 ถึงขนาดที่ดิน) · สวิตช์ "เทียบกับอะไร": ก) พื้นที่ที่ดิน ข) พื้นที่ชั้นใหญ่สุด · ค่าตั้งต้น: อาคารที่ให้ที่ว่างอยู่ใกล้ 30% (เห็นเส้นขอบเกณฑ์)
- **ภาพเปลี่ยน**: ระบายพื้นที่ว่างสีเขียว พื้นที่ปกคลุมสีเทา · ป้าย "ที่ว่าง X% ต้องการ ≥ Y%" · ถ้าสวิตช์ทั้งสองแบบให้ผลต่างกัน แสดงแถบคู่ขนาน 2 ผลพร้อมกัน
- **ค่าฉากเพิ่ม**: `floorsAreas?: number[]` (พื้นที่แต่ละชั้น เพื่อหาชั้นใหญ่สุด) — ตอนนี้ check.js สมมติชั้นใหญ่สุด = พื้นที่ฐานอาคาร ถ้าไม่เพิ่มก็ใช้ต่อได้
- **ผ่าน/ไม่ผ่าน**: ได้ (ตัวตรวจมีแล้ว คืน `alt` ให้) · **จุดที่ต้องตรวจ**: 30% ของอะไร (ที่ดิน / ชั้นใหญ่สุด / ฉบับที่ 33 ข้อ 6 เฉพาะอาคารสูง-ใหญ่พิเศษ) · ไม่ต้องใส่ตัวเลขใหม่

### `wall-opening-floors-wording` · สไลด์ 54 · needs-review
- **ฉาก**: ก
- **ผู้เรียนปรับ**: จำนวนชั้น (1–ช่วงที่ครอบ `lowMaxFloors`/`highMinFloors`) และความสูง แยกเป็น 2 ตัวเลื่อนอิสระ · สวิตช์ "ยึดตัวบท (ความสูง) / ยึดสไลด์ (ชั้น)" และโหมด "ดูทั้งสองพร้อมกัน"
- **ภาพเปลี่ยน**: เส้นร่น 2 ชุด (เส้นประ = ตามสไลด์ เส้นทึบ = ตามตัวบท) ถ้าสองชุดไม่ตรงกัน เน้นแถบแดง "สไลด์กับตัวบทให้คำตอบต่างกัน" · ปุ่มลัดตัวอย่างจากตารางกฎ: สูง 8 ม. 3 ชั้น และสูง 10 ม. 2 ชั้น
- **ค่าฉากเพิ่ม**: ใช้ `building.floors` ที่มีอยู่ · ไม่มีค่าใหม่ · ความสูงต่อชั้น = ต้องหาตัวเลข (ไม่ต้องใช้ ถ้าให้ปรับสองตัวอิสระ)
- **ผ่าน/ไม่ผ่าน**: ได้ — ตัวตรวจใหม่ `wallOpeningFloorsWording` คืนผลตามสไลด์เทียบกับผลตามตัวบท · **จุดที่ต้องตรวจ**: จะยึดแบบไหน (รอเจ้าของงาน) · สไลด์ไม่บอกเพดาน 23 ม. จึงแสดง "ไม่มีข้อมูล" ฝั่งสไลด์เมื่อสูงเกิน

- **ฉาก**: ก (มุมบน) · จำลองรูปสไลด์ 62: อาคารสูง 10 ม. ถนนกว้าง 15 ม. (ตัวเลขจากตารางกฎ)

- **ผ่าน/ไม่ผ่านได้ไหม**: ไม่ได้ (ไม่มีที่มา ตามตารางกฎ "ไม่ใส่ในตัวตรวจกฎ") · ได้แค่ภาพเปรียบเทียบตัวเลขในรูปกับระยะที่ผู้เรียนวางจริง · ต้องหา: ที่มาของ 1.50 (ตัวบทข้อ 41 เกี่ยวกับถนนแต่สไลด์ 52–69 ไม่ได้พูดถึง)

- **ฉาก**: ก (มุมบน ซูมที่ขอบเขตที่ดินข้างเคียง)

- **ฉาก**: ก (3 มิติ) · วางสนามเทนนิส 1 สนามมีรั้วรอบ (สร้างด้วยโค้ด) ริมถนน
- **ผู้เรียนปรับ**: ความสูงรั้ว (ทีละ 0.5 ม. พาดผ่าน `fenceHeightM`=10 ม.) · ขนาดสนาม
- **ภาพเปลี่ยน**: รั้วสูงขึ้น มีเส้นไม้บรรทัดเทียบ 10 ม. + ป้ายสี "ต่ำกว่า/เกินเส้น 10 ม."
- **ค่าฉากเพิ่ม**: `fence:{height, perimeter?, surroundsCourt:boolean}`
- **ผ่าน/ไม่ผ่านได้ไหม**: ไม่ได้ — สไลด์ไม่บอกว่าผลคือ "เป็นอาคาร" หรือ "ยกเว้น" และไม่พบกฎกระทรวงฉบับนี้ใน laws.json · แสดงได้แค่ "ต่ำกว่า/สูงกว่า 10 ม." ไม่ตีความผล · ต้องหา: ตัวบทกฎกระทรวงกำหนดสิ่งที่สร้างขึ้นอย่างอื่นเป็นอาคาร พ.ศ. 2544
- หมายเหตุ: ไม่ใช่เรื่องระยะร่น ถ้าเจ้าของงานเห็นว่านอกเรื่องบท ให้ย้ายไปบทนิยามอาคาร

## ส่วน 2 — ฉากค (ภาพตัดผนัง) — เรื่องผนังทึบ

มุมมองแบน 2 มิติ มี 2 โหมดสลับได้: (1) ตรงหน้าผนังหนึ่งด้าน (ตามรูปสไลด์ 63 บน) (2) ภาพตัดข้างพร้อมเขตที่ดินสองฝั่ง (ตามสไลด์ 63 ล่าง / 64 บน)

SceneParams ใหม่ของฉากนี้:
```js
wallElevation: {
  storeys: 2, bayWidth: 4.0, storeyHeight: /* ต้องหาตัวเลข */,
  openings: [{ kind: 'window'|'door'|'vent'|'glassBlock', storey, width, height, sillHeight, blockThicknessCm? }]
}
section: { buildingHeight, distToBoundaryLeft, distToBoundaryRight,
           wallSolid: { left: boolean, right: boolean }, parapetHeight, neighborConsent: boolean }
```

### `solid-wall-definition` · สไลด์ 63 · verified
- **ฉาก**: ค โหมด (1)
- **ผู้เรียนปรับ**: ลากบล็อกแก้วเข้าผนังเป็นแผงๆ · ความหนาบล็อก (ทีละ 1 ซม.) · ความสูงจากพื้นห้อง (ทีละ 0.1 ม.) · ขนาด/จำนวนบล็อกแก้ว · เพิ่มหน้าต่าง/ประตูธรรมดา (ปุ่ม)
- **ภาพเปลี่ยน**: ผนังด้านนั้นเปลี่ยนป้าย "ยังนับเป็นผนังทึบ" (สีเขียว) / "ไม่นับ" (สีแดง) · ป้ายสัดส่วน Σa/ΣA เป็น % เทียบ 10% (ตามภาพ Σa ≤ 0.1 ΣA) · บล็อกที่ไม่ผ่านเงื่อนไข (บางไป/ต่ำไป) กระพริบสีแดงพร้อมเหตุผล
- **ตรวจได้ไหม**: ได้ — เป็นภาพ "ลองเปลี่ยนแล้วดูว่ายังนับเป็นผนังทึบไหม" · ตัวตรวจใหม่ `solidWallDefinition` ใช้ `glassBlockMinThicknessCm` · `glassBlockMinHeightM` · `glassBlockMaxShare` · ผนังที่มีหน้าต่าง ประตู ช่องระบายอากาศ ช่องแสง = ไม่ทึบทันที
- หมายเหตุ: ตัวบทพูดถึง "พื้นที่ผนังแต่ละชั้นในด้านนั้นๆ" ⇒ ต้องคิดแยกชั้น (ตามรูป a1/A1 … a4/A4) ⇒ แสดงตารางสัดส่วนรายชั้น

### `solid-wall-near-boundary` · สไลด์ 62, 64, 65 · verified
- **ฉาก**: ค โหมด (2) + เชื่อมกับฉากก (ถ้าผู้เรียนปรับระยะ ก็เห็นผลในแปลน)
- **ผู้เรียนปรับ**: ระยะผนังถึงเขต (ตัวเลื่อน 0 → เกินเกณฑ์ ทีละ 0.1 ม. · ชิดเขตพอดี = 0) · ความสูงอาคาร (ทีละ 0.5 ม. ข้าม `maxHeightOnBoundaryM`) · สวิตช์ "ผนังด้านนั้นทึบ/มีช่องเปิด" · สวิตช์ "มีหนังสือยินยอมเจ้าของที่ดินข้างเคียง" · ความสูงผนังทึบบนดาดฟ้า (ทีละ 0.1 ม. ข้าม `parapetHeightM`)
- **ภาพเปลี่ยน**: ผนังด้านที่เข้าเกณฑ์ "ต้องทึบ" ระบายสีทึบ · ถ้าระยะน้อยกว่า `minSolidWallDistanceM` ไม่ชิดเขตจริง ป้ายแดง · ชิดเขต: เส้นความสูง 15 ม. + ผนังดาดฟ้า 1.80 ม. + ป้ายยินยอม ทุกข้อเป็นรายการติ๊กผ่าน/ไม่ผ่าน
- **ตรวจได้ไหม**: ได้ ผลรายข้อ 4 ข้อ (ระยะขั้นต่ำ · ความสูงเมื่อชิดเขต · ผนังดาดฟ้า · ยินยอม) · ความยินยอมเป็นเอกสาร ภาพทำได้แค่สวิตช์ ไม่ใช่การพิสูจน์

## ส่วน 3 — ฉากง (ตึกแถว)

SceneParams ใหม่:
```js
rowhouse: {
  rows: [{ units: 10, unitWidth: /* ต้องหาตัวเลข */, depth, gapToNextRow }],
  backSpace: { width, projections: [{ kind: 'fireEscape'|'other', depth }] },
  generation: 'new' | 'old'      // ตามสไลด์ 55
}
```
มุมมองบน: คูหาเรียงเป็นแถว (สี่เหลี่ยมส้มตามรูปสไลด์ 55 สร้างเองด้วยโค้ด ไม่ใช้รูปสไลด์) ทางเดินหลังเป็นแถบ ถนนอยู่ด้านหน้า
